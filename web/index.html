Branch Merger

Select branches, press Apply: a new branch is cut from the base branch and the selected branches are merged into it, in order.

Branch Merger runs through its local helper: start python3 main.py and open http://127.0.0.1:8765.

Merge strategy
Fix conflicts in
{folder} the conflict folder, {file} the first conflicted file, {line} its first conflict. Quote like a shell; it runs without one. With no placeholder, the folder is added at the end. Examples: subl {folder} {file}:{line}, open -a "IntelliJ IDEA" {folder}.
The conflict view's Open in editor stops the merge on the branch's conflicts in a folder next to your clone. Fix them there and press Save fix: every later dry run and Apply reuses the fix (git rerere).

Jira

Create a token at id.atlassian.com. Leave all three empty to use the helper's JIRA_* environment variables.
The Selected list shows the status of the issue named in each branch. Statuses not listed here are flagged; leave it empty to flag only done issues.
